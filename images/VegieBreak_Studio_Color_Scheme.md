# VegieBreak Studio — Color Scheme

The logo uses a **neon cyberpunk palette** with organic greens and warm pink-orange highlights.

> The hex values below are representative palette values, not exact pixel samples from the logo.

## Logo Palette

| Color | Hex | Suggested use |
|---|---|---|
| Electric lime | `#C8FF38` | Leaves and primary highlights |
| Neon green / teal | `#00DCA8` | Leaf shadows and cool accents |
| Hot pink | `#FF4B91` | Bulb shading and headphone glow |
| Vibrant orange | `#FF6B22` | Warm highlights and sound accents |
| Electric cyan | `#35DFFF` | Headphone edges and cool rim lighting |
| Deep midnight | `#171322` | Dark outlines and shadows |

## Recommended Background Colors

### 1. Midnight Charcoal — `#101018` (Recommended)

Best for the DAW interface. Makes the neon accents stand out without competing with the logo.

### 2. Deep Navy — `#080B14`

A futuristic, premium look, especially suitable for a modern audio workstation.

### 3. Dark Plum — `#1A1021`

Adds warmth and complements the pink-purple shading in the logo.

### 4. Warm Off-White — `#F4F0E8`

Suitable for documentation, light-mode screens, and promotional material. Not the first choice for the main DAW interface.

## Suggested DAW UI Palette

| UI role | Hex | Purpose |
|---|---|---|
| Main background | `#101018` | Primary application background |
| Panels | `#1C1C29` | Tool panels, mixer, browser, and secondary surfaces |
| Primary action | `#C8FF38` | Main buttons, active states, and key highlights |
| Secondary accent | `#FF4B91` | Selected clips, accent indicators, and highlights |
| Cool accent | `#35DFFF` | Audio-related indicators, meters, and secondary states |
| Warm accent | `#FF6B22` | Warnings, recording accents, or attention states |
| Text | `#F4F0E8` | Primary text on dark surfaces |
| Muted text | `#A9A2B7` | Secondary labels and subdued UI text |
| Borders / dividers | `#393342` | Subtle panel boundaries and separators |

## Recommendation

Use `#101018` as the main background, `#1C1C29` for panels, and `#C8FF38` for primary actions. Reserve pink and cyan for secondary accents. Avoid making every UI element glow; use neon selectively so the interface remains readable and comfortable during long music sessions.
